# Documentation

This directory contains the detailed documentation for the KGQA workflows implemented in this repository.

## Guides

- [Navigation](navigation.md): iterative graph navigation, prompting, memory, action selection, and context handling.
- [Think-on-Graph](tog.md): local ToG adaptation, upstream compatibility, search behavior, parsing, evaluation, and versioning.
- [Subgraph QA](subgraph.md): subgraph-at-once QA, sampling strategies, and retrieval mode.
- [Datasets](datasets.md): expected dataset layout, title mappings, and the paper datasets.
- [Reproducibility](reproducibility.md): scripts and settings used for the paper experiments.
- [Results and Analysis](results.md): output structure, metrics, and analysis utilities.
- [Development](development.md): repository architecture, key modules, tests, and development tools.

For installation, backend configuration, and the shortest path to reproducing the paper results, start with the repository [README](../README.md).
